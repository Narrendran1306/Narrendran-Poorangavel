# Narrendran Poorangavel — Full Stack Developer Portfolio

A modern, responsive single-page developer portfolio showcasing my experience, technical skills, projects, education, and professional journey as a **Full Stack Developer**.

Built with **Next.js 15, TypeScript, React, and CSS Modules**, with a focus on clean UI, responsive design, reusable components, accessibility, and maintainable code.

## Features

* Sticky glass-effect navbar with active section tracking
* Dark / Light theme with system preference support
* Theme persistence using localStorage
* Desktop cursor glow effect
* Scroll-to-top button
* Skills & Expertise section with responsive layout
* Filterable skills and projects
* Professional experience timeline
* Education cards
* Featured projects section
* Contact section with social links
* Fully responsive design for devices from 320px+
* Smooth scrolling and entrance animations
* Reduced-motion support for accessibility
* SEO metadata
* Centralized portfolio content for easy updates
* MUI Icons only — no MUI UI components

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

## Project Structure

```text
app/
├── App Router entry
│
screens/
├── Section components
│
components/
├── Reusable UI components
│
data/
└── portfolio/
    └── portfolioDetails.ts
```

### Content Management

All portfolio content is centralized in:

```text
data/portfolio/portfolioDetails.ts
```

This includes:

* Personal information
* Navigation
* Skills
* Expertise
* Projects
* Experience
* Education
* Certificates
* Contact information
* Social links

This structure makes it easy to update portfolio content without modifying the UI components.
